# Pasta docs

Coloque esta pasta na raiz do projeto, no mesmo nível de `src`, `public`, `package.json` e `README.md`.

Estrutura:

```text
site-rafaela/
├── docs/
├── public/
├── src/
├── README.md
└── package.json
```

Os arquivos de preview deste kit são mockups vetoriais editoriais baseados na identidade descrita do projeto.
Quando o site estiver finalizado, substitua os arquivos `preview-*.svg`, `desktop.svg`, `mobile.svg` e `demo.gif`
por capturas reais mantendo os mesmos nomes. O README continuará funcionando sem alterações.
